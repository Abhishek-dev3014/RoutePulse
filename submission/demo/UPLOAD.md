# Add the demo to Devfolio

1. Preview `routepulse-demo-narrated.mp4` with audio enabled.
2. If Devfolio asks for a video URL, upload the MP4 to your YouTube account as Unlisted. Suggested title: RoutePulse | WILD BUGS PS 02 | Working Product Demo.
3. Optionally upload `narration-en.srt` as English subtitles. Sentence timing is approximate; check YouTube preview. The video also contains the original visible captions.
4. Paste the share URL into Project Media → Add demo video. If the dialog accepts a local video file, select the MP4 directly.
5. Test embedded playback while signed out, then save the project draft.

The video has synthetic macOS Samantha narration over the original app recording. The footage and simulation results are unchanged. No upload or public submission has been performed.
